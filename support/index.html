Time Manager is meant to be understandable without a manual. When something does not behave that way, tell us.

Permissions

Usage Access looks disabled

Open Time Manager → Settings → Usage Access, then grant usage access in Android's system settings. Return to the app afterward.

Categories

An app is uncategorized

Keep an internet connection available and allow the category sync to complete. Unknown apps may need a one-time backend/AI classification before the result is cached.

Insights

AI Insight is not ready

Make sure Usage Access is enabled and Time Manager has enough recent usage data to build the summary. AI Insights are generated only when you request them.

Limits

How do time budgets work?

Set a total daily budget, then assign portions to categories. Unassigned time remains flexible and can be moved when needed. These are planning guardrails, not Android-level app blocks.

Tour

Replay the guided tutorial

Open Settings → Help & guide → Quick app tour. The tour moves through the real app and points to each feature directly.
