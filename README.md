# Unknowns Developerz website

Static, dependency-free brand website for **Unknowns Developerz**.

## Included

- Brand homepage
- Time Manager product showcase using real app screenshots
- Human-readable Time Manager privacy policy at `/privacy/`
- Support page at `/support/`
- Responsive navigation
- Reduced-motion support
- Lightweight matrix/cyber visual layer
- No build step and no third-party front-end dependencies

## Local preview

From this directory:

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080`.
